# From photograph to loom: verified digital records of Koh Yo hand-woven textile patterns

Code, photographs, results and loom files for the paper

> Kittikant, T. & Praphaphankul, N. (2026). From photograph to loom: verified digital records of endangered Koh Yo hand-woven textile patterns. Submitted to *Studies in Conservation*.

The pipeline turns a hand-held photograph of a supplementary-weft cloth into a pattern tile, a cell draft and a weaving draft (threading, tie-up, treadling) exported as WIF and as TC2 Jacquard image files, and measures how far each record can be trusted. Every number in the paper is read from the JSON results files in `data/`.

## Layout

| Path | Contents |
|---|---|
| `src/analyze.py` | Main pipeline and verification: illumination flattening, rotation, shell-consistency lattice rule, affine and homography rectification, fold refinement, re-registration, Otsu draft, phase-aware cell grid, draft factoring, shaft projection, WIF and TC2 export, bootstrap and round trips. Writes `data/results.json`, `data/loom/<id>/`, `data/npz/`. |
| `src/analyze_v2.py` | Baseline lattice rules, fold-residual curves, Noise2Noise denoiser, mixture draft with Markov prior, resolution and noise sweeps. Writes `data/results_v2.json`. |
| `src/ml_lattice.py` | Gradient-boosted lattice selector trained on synthetic cloth. Writes `data/results_ml.json`. |
| `src/symmetrize.py` | Symmetry-regularised drafts and their loom files (`data/loom/<id>/sym_*`). Writes `data/results_sym.json`. |
| `src/advanced.py` | Registration super-resolution, displacement vote map, chi-square symmetry test, soft draft, texture distance, Hu moments. Writes `data/results_adv.json`. |
| `src/make_figures*.py` | Every figure panel in the paper (`figures/panels/`); `make_figures_method.py` draws the method figures. |
| `src/digitize_poc.py` | The earlier proof-of-concept converter, for reference only. |
| `data/raw/` | The five photographs P1 to P5 (Ratchawat, Dok Phakakrong, Dok Rotsukhon with Luk Kaeo, Kamphaeng, Luk Kaeo). |
| `data/loom/<id>/` | `<id>.wif` and `<id>_sym.wif` (Otsu and symmetry-regularised drafts), `tc2_8x8_repeats.tif` and `sym_tc2_8x8_repeats.tif` (indexed TIFF for the TC2 loom), point-paper charts, mean tile, `metrics.json`. |
| `data/results*.json` | All verification numbers. `data/ablation_fixed_origin.json` (`src/ablation_fixed_origin.py`) is the round trip without the cell-grid origin search; `data/symmetry_noise_test.json` (`src/symmetry_noise_test.py`) is the symmetry noise test; `data/chance_projection_cost.json` (`src/chance_projection_cost.py`) is the random-draft baseline for the shaft projection. |
| `paper/` | LaTeX source of the manuscript and supplementary material (`main.tex` with its Appendix, `refs.bib`, `sic.bst`); figure panels are in `figures/panels/`. |

## Reproducing the results

Python 3.11 or later. About 20 minutes on a two-core laptop CPU.

```
pip install -r requirements.txt
bash run_all.sh
```

`data/npz/` (intermediate arrays used by the figure scripts, about 100 MB) is not stored in the repository and is regenerated by `src/analyze.py`.

## Using the pipeline on a new photograph

Add the photograph to `data/raw/` and an entry to the `PATTERNS` list at the top of `src/analyze.py` with an id, the file name, the pattern name in English and Thai, and the weaver's heddle count (used only for verification), then run `python3 src/analyze.py`. Guidance on taking a suitable photograph (at least six repeats in the frame and at least four pixels per pattern cell) is given in the paper.
